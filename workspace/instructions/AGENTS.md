# AGENTS.md

## Testing
- Framework: Vitest
- Execution: `bun test`
- File naming: `*.test.ts`

## Coding Standards
- Prioritize pure functions
- Represent errors as return values ​​rather than exceptions
- Explicitly define types (usage of `any` is prohibited)

## Editing Guidelines
- Modify existing code using diff-based edits
- Match the style of existing files when creating new ones
